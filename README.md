  <br/>
  <img src="https://img.shields.io/badge/Frontend-In%20progress-orange?style=flat-square" alt="Frontend status" />
  <img src="https://img.shields.io/badge/Backend-Planned-lightgrey?style=flat-square" alt="Backend status" />
</p>

<table>
  <tr>
    <td width="50%" valign="top">
      <h4>Features</h4>
      <ul>
        <li>Home page with announcement bar, hero, collections, best sellers, benefits, customer reviews and footer.</li>
        <li>Product pages generated automatically from a JSON data file (<code>/products/[slug]</code>).</li>
        <li>Purchase panel with size selector, quantity control and add-to-cart / buy-now actions, including validation.</li>
        <li>Design system built with Tailwind CSS v4 design tokens.</li>
        <li>Accessibility basics: semantic HTML, ARIA labels and descriptive image alt text.</li>
        <li>Fast pages: static output, lazy-loaded images and JavaScript only where needed.</li>
      </ul>
    </td>
    <td width="50%" valign="top">
      <h4>Technical decisions</h4>
      <ul>
        <li><b>Astro islands:</b> pages are static HTML; only the purchase panel is a React component.</li>
        <li><b>Data-driven pages:</b> adding a product to the JSON creates its page; later replaced by the REST API.</li>
        <li><b>Design tokens:</b> brand colors are defined once in <code>global.css</code>.</li>
        <li><b>Conventional Commits:</b> <code>feat:</code>, <code>fix:</code>, <code>style:</code>, <code>refactor:</code>, <code>docs:</code>.</li>
        <li><b>Layered backend:</b> controllers, services and repositories, with DTOs and centralized error handling.</li>
      </ul>
    </td>
  </tr>
</table>

**Architecture**

```text
Browser ─► Astro / React frontend ─► Spring Boot REST API ─► MySQL
                                          │
                                          └─► Payment gateway (webhooks)
```

<details>
  <summary><b>Project structure</b></summary>

```text
src/
  components/
    home/      Hero, Collections, BestSellers, Benefits, Reviews
    layout/    AnnouncementBar, Navbar, Footer
    product/   ProductPurchase (React island), Recommendations
  data/        products.json
  layouts/     Layout.astro
  pages/       index.astro, products/[slug].astro
  styles/      global.css (design tokens)
  utils/       format.ts
public/
  images/      Brand and product images
```
</details>
